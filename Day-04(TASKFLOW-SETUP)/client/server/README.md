# TaskFlow - MEAN Stack Task Manager

## Project Goal

TaskFlow is a MEAN Stack task management application that helps users organize and track their daily work efficiently.

This project will be developed throughout the internship using:

- MongoDB
- Express.js
- Angular
- Node.js

---

## Planned Features

- User Authentication
- Dashboard
- Create Tasks
- Edit Tasks
- Delete Tasks
- Task Status
- Due Dates
- Search & Filter
- Projects
- User Profile

# Temperature Converter

## Description

A simple Temperature Converter built using HTML, CSS, and JavaScript.

It converts:

- Celsius → Fahrenheit
- Fahrenheit → Celsius

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- User-friendly interface
- Input validation
- Accurate temperature conversion
- Responsive design

## How to Run

1. Open index.html in your browser.
2. Enter a temperature.
3. Select conversion type.
4. Click the Convert button.
5. View the result.

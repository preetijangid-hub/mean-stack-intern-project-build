# 🌡 Temperature Converter

## Overview

A simple Temperature Converter built using HTML, CSS and JavaScript.

Users can convert temperatures between Celsius, Fahrenheit and Kelvin.

---

## Features

- Celsius → Fahrenheit
- Fahrenheit → Celsius
- Celsius → Kelvin
- Kelvin → Celsius
- Fahrenheit → Kelvin
- Kelvin → Fahrenheit
- Input Validation
- Reset Button
- Responsive Design


## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

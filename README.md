# FizzBuzz Checker

## Description

This project is a simple FizzBuzz Checker built using HTML, CSS, and JavaScript.

## Features

- Input Validation
- Pure Function
- Responsive UI
- Error Handling
- Clean Code

## Technologies

- HTML
- CSS
- JavaScript

## Rules

- Multiple of 3 → Fizz
- Multiple of 5 → Buzz
- Multiple of both → FizzBuzz
- Otherwise returns the number

# User Stories

## Story 1: User Registration

As a new user,
I want to create an account,
so that I can manage my tasks.

### Acceptance Criteria

- User can register using email and password.
- Required fields are validated.
- Registration is successful.

## Story 2: User Login

As a registered user,
I want to log into my account,
so that I can access my tasks.

### Acceptance Criteria

- Valid credentials allow login.
- Invalid credentials display an error.
- User is redirected to the dashboard.

## Story 3: Create Task

As a user,
I want to create a new task,
so that I can organize my work.

### Acceptance Criteria

- User can enter title and description.
- User can set priority.
- User can assign a due date.
- Task is saved successfully.

## Story 4: Edit Task

As a user,
I want to edit an existing task,
so that I can update task details.

### Acceptance Criteria

- User can modify task details.
- Changes are saved successfully.

## Story 5: Delete Task

As a user,
I want to delete a task,
so that I can remove unnecessary tasks.

### Acceptance Criteria

- Confirmation message is displayed.
- Task is permanently deleted.

## Story 6: Mark Task as Completed

As a user,
I want to mark a task as completed,
so that I can track my progress.

### Acceptance Criteria

- Completed task status is updated.
- Completed tasks are displayed separately.

## Story 7: Search Tasks

As a user,
I want to search for tasks,
so that I can quickly find them.

### Acceptance Criteria

- Search works using task title.
- Matching tasks are displayed instantly.

## Story 8: Filter Tasks

As a user,
I want to filter tasks,
so that I can focus on important work.

### Acceptance Criteria

- Filter by Priority.
- Filter by Status.
- Multiple filters work together.

## Story 9: Receive Notifications

As a user,
I want reminders before task deadlines,
so that I don't miss important work.

### Acceptance Criteria

- Reminder is shown before due date.
- Notification displays task details.

## Story 10: Update Profile

As a user,
I want to update my profile,
so that my information stays current.

### Acceptance Criteria

- User can update profile details.
- Password can be changed securely.

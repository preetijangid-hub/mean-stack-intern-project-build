# FizzBuzz Checker

## Description

A simple JavaScript application that checks whether a number is:

- Fizz (divisible by 3)
- Buzz (divisible by 5)
- FizzBuzz (divisible by both 3 and 5)
- Otherwise displays the number itself.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open index.html in your browser.
2. Enter a number.
3. Click the Check button.
4. View the result.
